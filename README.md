# cloveode.com

Marketing site for Cloveode Technologies. Next.js 16, TypeScript, Tailwind v4, Motion, Lenis. Hosted on Vercel.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
```

Copy `.env.example` to `.env.local` and add a Resend API key to make the contact form deliver email.

See `CLAUDE.md` for architecture notes and the visual QA workflow.
